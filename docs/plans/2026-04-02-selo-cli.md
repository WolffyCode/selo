# Selo CLI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and publish a Node.js CLI named `selo` that reads CC Switch Claude providers, keeps the picker in sync with CC Switch changes, and launches `claude` with a frozen per-run settings snapshot.

**Architecture:** The package is split into a thin executable, a CC Switch store layer, pure core modules for provider resolution and launch planning, and a terminal UI loop that can refresh when CC Switch files change. Global-install compatibility is handled by storing local state in the user config directory rather than the install directory.

**Tech Stack:** Node.js, built-in `node:test`, `sqlite3` CLI, terminal raw mode, temporary JSON files.
